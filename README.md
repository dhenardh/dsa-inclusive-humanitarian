# DSA Website

Public website for **DSA — Remote Sensing & Inclusive Humanitarian Toolkit**.

## Publish with GitHub Pages
1. Create a **public** GitHub repository (example: `dsa-website`).
2. Upload everything in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then **Save**.
6. Wait for GitHub Pages to publish and use **Visit site**.

The site is static HTML/CSS/JavaScript and contains no server-side code.

## Important before sharing
- Check the bank account and SWIFT/BIC details yourself.
- Replace/expand the development log only with verified releases.
- Add financial figures only from verified records.
- Never publish donor personal data without permission.
- The `reports/` folder is ready for future public transparency PDFs.

## Language
Use ID / EN / DE buttons in the top-right corner.
